# Configura-es-de-Rede
 **Projeto prático de redes desenvolvido durante minha formação em Tecnologia e estudos em Cibersegurança, utilizando o Cisco Packet Tracer.**

Este projeto apresenta a implementação e configuração de uma infraestrutura de rede simulada, com o objetivo de aplicar na prática conceitos fundamentais de **redes de computadores, comunicação entre dispositivos, endereçamento IP e configuração de equipamentos de rede**.

## 🎯 Objetivo do projeto

O principal objetivo deste laboratório foi **projetar, configurar e validar uma rede de computadores em ambiente simulado**, colocando em prática conceitos estudados em redes.

Durante o desenvolvimento, foram trabalhados conceitos relacionados a:

- Endereçamento IPv4;
- Configuração de dispositivos de rede;
- Comunicação entre hosts;
- Configuração de switches e roteadores;
- Conectividade entre diferentes segmentos da rede;
- Testes e validação da comunicação;

  ## 🏗️ Ambiente utilizado

| Recurso | Tecnologia |
|---|---|
| Simulador | Cisco Packet Tracer |
| Equipamentos | Roteadores e Switches Cisco |
| Hosts | Computadores simulados |
| Protocolo de rede | IPv4 |
| Área de estudo | Redes de Computadores |
| Aplicação | Laboratório prático |

## 🔧 O que foi desenvolvido

O laboratório foi construído a partir de uma topologia de rede simulada, envolvendo dispositivos de infraestrutura e computadores.

### Principais atividades

**1. Planejamento da topologia**

Foi estruturada uma topologia para representar a comunicação entre os dispositivos da rede.

**2. Endereçamento IP**

Foram definidos endereços IPv4 para os dispositivos, permitindo a identificação e comunicação entre os diferentes hosts.

**3. Configuração dos equipamentos**

Os dispositivos de rede foram configurados de acordo com as classes de cada rede.

**4. Testes de conectividade**

Foram realizados testes para verificar se os dispositivos conseguiam se comunicar corretamente.
